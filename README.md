# Stickman-Project

A cable-hero practice game for mobile MOBA players: a stickman, a fixed top-down MOBA camera, and drills for
straight and chained cable casts. Built with Unity 6000.3.29f1 (URP, Input System). Android first.

- Rules for contributors and agents: [AGENTS.md](AGENTS.md)
- Design: [docs/GAME_SPEC.md](docs/GAME_SPEC.md) · Progress: [docs/PROGRESS.md](docs/PROGRESS.md)
- Builds: GitHub Actions (GameCI) on every push to `main` — see the Actions tab for APK / Linux / Windows artifacts.
