# CONTROLS

| Aksi | HP (sentuh) | PC (tes) |
|---|---|---|
| Gerak | joystick kiri (mengambang) | WASD / panah |
| Serangan dasar | tombol `ATK` kanan bawah | klik kiri / `Space` |
| Skill 1 – Spin | tombol `S1` | `Q` |
| Skill 2 – Cable | ketuk = quick cast · tahan + geser = aim · geser ke atas kiri tombol = cancel | `E` (tahan = aim ke mouse, lepas = lempar) |
| Ultimate – Dash | tombol `ULT` | `R` |
| Geser Kamera (Free Pan) | geser area kosong layar atau tahan/geser minimap (otomatis kembali saat dilepas; diatur oleh *Camera Pan Sensitivity*) | tahan klik kanan / klik tengah + geser (atau geser minimap) |
| Mode & Alat Latihan | tombol bar atas (`Free` / `Drill` / `Course` / `Tools`: Inf Energy, No CD, Slow 0.5x, +Dummy, +Patrol, Clear Bots, Teleport) | tombol bar atas atau `Tab` (`Tools`) |
| Pengaturan & Tata Letak | tombol `Settings` -> slider kamera/pan/aim/deadzone, toggle fitur, `Edit Layout` (drag & drop tombol sentuh) | sama dengan HP |
